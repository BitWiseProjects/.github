# BitWise

Electronics and embedded software, taught through hands-on builds — a real board on the bench, a real scope trace on screen, mistakes left in.

**Channel:** [youtube.com/@BitWiseDex](https://youtube.com/@bitwisedex)
**Site:** [bitwisedex.com](https://bitwisedex.com)

Public repos here are the code that accompanies episodes — firmware, math, and viewers built for the builds themselves, meant to be read in the same order they're flashed.
